# 推荐与留存日报 — 2026-07-28

## 今日头条：论文精读——反事实互惠推荐，用于「人配人」匹配

arXiv 论文《Counterfactual Reciprocal Recommender Systems for User-to-User Matching》针对在线交友等「双边互惠」场景指出：传统日志按「已曝光对」训练，会被既有曝光策略污染，导致模型只学到「被系统推过的」而非「真正互相合适的」匹配。作者引入反事实 / 倾向加权纠偏，让模型直接优化「双方都会正向回应」的互惠目标，而非单侧点击。

「为什么重要」：交友推荐的目标从来不是「A 喜欢 B」，而是「A、B 互相喜欢并成功对话」。用曝光有偏的历史日志训练互惠模型时，反事实纠偏为「去除幸存者偏差、逼近真实互惠概率」提供了可落地的方法论，直接关系匹配质量与回复率。

**Save, Revisit, Retain：以「回访行为」作为可扩展的留存信号**

论文《Save, Revisit, Retain: A Scalable Framework for Enhancing User Retention in Large-Scale Recommender Systems》提出，把「用户保存并再次回访内容」作为可扩展的留存信号与优化目标，而非只优化即时点击。框架在工业级推荐系统上验证：以「回访 / 复访」为代理指标进行建模与排序，能带来长期留存的提升。

「为什么重要」：交友产品的北极星是「用户持续回来并成功匹配」，而非单次滑动。把「保存 / 回访」等长期信号纳入排序目标，可缓解「只追即时点击导致长期流失」的短视优化陷阱，是留存工程的重要思路。

[原文链接](https://arxiv.org/abs/2511.18013)

**Retention-Optimized Two-Sided Matching：超越「匹配最大化」**

论文《Beyond Match Maximization and Fairness: Retention-Optimized Two-Sided Matching》主张，双边匹配平台不应只最大化即时匹配数或公平性，而应把「双方留存」直接写进目标函数——因为把稀缺的高需求用户过度分配，会加速另一侧用户流失。作者给出以留存为目标的匹配分配方法。

「为什么重要」：交友是典型双边市场，「热门用户过曝 → 冷门侧流失」是留存杀手。把留存纳入匹配分配目标，为 CMB 平衡供需两侧、延长整体用户生命周期提供了可操作的框架。

[原文链接](https://arxiv.org/pdf/2602.15752)

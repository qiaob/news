# 推荐与留存日报 — 2026-08-01

## 今日头条：Pinterest 把「留存」当成推荐系统一等目标——Pinner Progression 拉动周活增长

Pinterest 工程团队 7 月发文披露「Pinner Progression」项目：不再只优化单次点击/停留，而是把留存作为首页推荐系统的一等优化目标。核心做法是在「逐动作的序列化用户理解」之上，叠加一层「持续性的用例（use-case）表征」——刻画用户长期意图的画像，从而更可靠地预判下一步、制造「惊喜式发现」。实验显示，留存收益在用例采纳度的顶部十分位急剧加速，暗示存在「广度采纳达到阈值后留存复利」的门槛效应。

「为什么重要」：交友产品同样苦于「短期指标涨、长期留存不涨」；把稳定的长期意图表征与序列信号结合、并直接对留存建模，是把「多聊几句」变成「长期留在平台」的可迁移思路。

**arXiv 新论文：让 LLM 重排「一次前向、任意顺序」都稳定——InvariRank**

论文《One Pass, Any Order: Position-Invariant Listwise Reranking for LLM-Based Recommendation》针对一个实操痛点：用 LLM 做候选重排时，输出排序会随候选在 prompt 中的排列顺序而漂移，难以复现。作者提出 InvariRank，在单次前向传播中对全部候选打分，既保持有竞争力的排序效果，又能在候选任意置换下产出稳定一致的结果，显著降低了 LLM 重排的方差与工程不确定性。

「为什么重要」：把 LLM 塞进召回后的重排层是当下热点，但「顺序敏感 / 结果不可复现」是上线拦路虎；位置不变的一次性打分，让 LLM 重排更接近生产可用，对交友场景的双边互惠重排尤其有价值。

[原文链接](https://arxiv.org/abs/2604.27599)

**arXiv 新论文：LLM 辅助重排会不会「放大」极端内容？**

论文《LLM-Assisted Reranking to Operationalize Nuanced Objectives in Recommender Systems》用零样本、指令式提示对 YouTube 侧边栏候选做重排，系统性检验一个安全问题：当用自然语言目标（如「更相关」「更符合价值观」）去驱动 LLM 重排时，是否会在无意中放大对意识形态极端内容的曝光。研究给出了量化的观察与缓解方向，提醒「用一句话定义排序目标」的便利背后藏着可控性风险。

「为什么重要」：交友与社交推荐越来越用自然语言目标做重排/调优，这类研究说明「提示即策略」必须配套审计与护栏，否则可能在留存指标之外制造安全与合规隐患。

[原文链接](https://arxiv.org/abs/2606.02883)

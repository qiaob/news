# AI 与科技日报 — 2026-11-05

## 今日头条：腾讯发布混元 Hy4，视觉理解与电脑操作成为旗舰模型标配

腾讯混元于 11 月 4 日发布新一代大模型 Hy4 正式版：总参数 7700 亿的混合专家架构、单次激活约 490 亿参数，上下文达 100 万 token，并首次引入视觉能力，可做精细图像处理、复杂图表分析与数学视觉推理；同时能通过图形界面和命令行操作电脑，组合感知、推理与工具调用完成长程任务。模型已上线腾讯云 TokenHub、元宝、WorkBuddy/CodeBuddy 等入口，但承诺的开源权重与系统卡尚未发布，目前只能通过 API 和腾讯自有产品使用。

「为什么重要」：国产旗舰把"看屏幕、动手操作"做成标配，交友产品里的 AI 助手、内容审核与破冰工具多了一个高性价比选项；但权重未落地前，自托管与合规审查都还无从谈起，需等开源兑现后再评估接入。

**Anthropic 用 Claude 解析首个原核生物 vault 蛋白结构**

Anthropic 生物实验室 11 月 4 日公布新成果：一种源自噬菌体的蛋白 L05 能在细菌内自组装成由 96 个蛋白拷贝构成的巨型中空"vault"颗粒，团队用冷冻电镜解析出其三维结构，为原核生物中的首例。Claude 贯穿全程——检索约 150 亿条预测蛋白序列、设计 DNA 构建、优化纯化流程（把三天的纯化缩短到约 90 分钟）、处理电镜数据，首个结构模型 34 小时即完成；团队也坦承 Claude 的一处建议曾让实验延误两周。成果已投 bioRxiv 预印本，尚未同行评审。

「为什么重要」：大模型正从"写字助手"变成能嵌入实验流程的科研协作者，价值要用可验证的产出而非对话质量衡量；交友产品选型时同理，应看模型在具体任务上的实测结果，并保留人工纠错环节。

**CrowdStrike 推出 AI 红队服务，用攻击型 Agent 自动串联漏洞**

CrowdStrike 在 Fal.Con Europe 上发布 Agentic Adversary Emulation（早期访问阶段）：由其安全模型家族 SafeMind 驱动，像真实攻击者一样把客户环境中的漏洞、错误配置与身份缺口串联成可利用的攻击路径，给出按优先级排序的修复建议，修复后自动重跑攻击验证路径已关闭。CrowdStrike 称其追踪到的真实案例中，已有 Agent 把单个漏洞串联成集群管理员权限并外泄 726 个数据库，全程无人操作键盘。

「为什么重要」：攻防两端都在 Agent 化，平台方的信任与安全工作也要从"单点漏洞扫描"升级为"攻击路径治理"；交友应用持有大量敏感私聊与位置数据，这类自动红队值得纳入安全评估清单。

**Google 默认关闭中小学生 AI 工具，学校须主动开启**

据 AFP 报道，Google 宣布将面向 K-12 学生账号默认关闭其 AI 工具，包括 Gemini、Gemini Notebook、Gemini in Classroom 以及带 AI 功能的 Search，须由学校管理员主动开启后学生才能使用；新规将从美国开始向全球推出，具体日期未定。此前 Google 因在教育场景积极推送 AI 功能受到批评，学校方面对课堂如何用 AI 仍在争论之中；调整后，学校也无法再给学生提供"无 AI 功能"的 Google Search。

「为什么重要」：头部平台在未成年人场景从"默认开"转向"默认关+机构 opt-in"，这是年龄分层与未成年保护的明确信号；交友社交产品面向年轻用户时，AI 功能的上线策略与年龄门设计需要提前对齐这一趋势。

[原文链接](https://www.gmanetwork.com/news/scitech/technology/1008334/google-turns-off-ai-for-schoolchildren-by-default/story/)

**Anthropic 为 Claude 推出 Message Threads 公测，长会话延迟降约 35%**

Anthropic 为 Messages API 推出 Message Threads 公共测试：Agent 会话首次发送完整对话后，后续只需提交新增消息并带上 thread ID，无需反复重传全部历史。官方称在 50 万至 100 万 token 的超长请求上，首 token 延迟中位数下降约 35%。这针对的正是长程 Agent 任务里"上下文越滚越大、每步都变慢变贵"的痛点，与 Kong、Honeycomb 等厂商同期发布的 Agent 治理工具一道，显示基础设施层正围绕 Agent 形态重构。

「为什么重要」：长会话成本与延迟直接决定 AI 功能能否规模化上线；这类 API 层优化不需要改产品逻辑就能降本，交友产品若在做多轮 AI 对话或 Agent 功能，应尽早评估切换收益。

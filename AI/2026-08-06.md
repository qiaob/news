# AI 日报 — 2026-08-06

## 今日头条：OpenAI 未发布模型 Astra 攻克 10 道悬置多年的数学难题，附可机器校验的 Lean 4 证明

OpenAI 于 8 月初宣布，其「下一代主力模型」Astra（尚未公开发布）解出了 10 道悬置十年以上的数学与理论计算机科学难题，覆盖群论、von Neumann 代数、高维几何、量子复杂度、格密码与极值组合。团队公开了一份 249 页手稿与 GitHub 上的 Lean 4 证明证书（Apache 2.0），仓库 `sorry` 计数为 0，意味着每一步都通过了形式化校验；其中最受关注的是首次显式构造出「非 sofic 群」，回答了自 1999 年 Gromov 提出该概念以来悬而未决的问题。OpenAI 称按 Sol API 价格，生成这些解答的 token 成本约 2,000 美元。

「为什么重要」：模型从「会答题」走向「能产出可验证的新知识」，且成本极低——对交友产品意味着未来在匹配诊断、反欺诈规则推导、A/B 结论的形式化验证等需要「可审计推理」的环节，AI 有望承担更硬核的角色。

**阿里通义发布 Qwen3.8-Max：2.4 万亿参数 MoE，多项基准超 GPT-5.6 Sol 与 Fable 5**

8 月 3 日，阿里云通过 Model Studio 全球开放 Qwen3.8-Max 的 API，参数规模 2.4 万亿（稀疏 MoE，每 token 激活约 950 亿）。官方基准显示其 OSWorld-Verified 得 86.1、PaperBench 得 93.0，均领先 GPT-5.6 Sol Max 与 Fable 5；但在 SWE-bench Pro（67.7 对 Fable 5 的 80.0）等纯编码/推理项上仍落后。阿里承诺约一周内开放 Qwen3.8-Max 与更小的 Qwen3.8-27B 权重。

「为什么重要」：非美一线开源/半开源模型继续以「部分基准反超 + 开放权重 + 低价」逼近头部，给交友产品在自建推荐、内容审核、对话辅助等场景提供了成本更低、可私有化部署的备选，降低对单一美国供应商的依赖。

**MCP 发布 2026-07-28 规范：转向无状态内核，新增 Tasks 长任务扩展与更强鉴权**

Model Context Protocol 发布了自诞生约 20 个月来最大一次修订：协议核心从「双向有状态」改为「请求/响应无状态」，让远程 MCP server 可直接置于普通轮询负载均衡之后、客户端按 TTL 缓存 `tools/list`；同时引入首批官方扩展，包括 AWS 贡献的 Tasks（可靠的长时运行智能体）、MCP Apps 与 EMA，并改进了授权机制以降低 OAuth 混淆攻击风险。部分改动不向后兼容，废弃特性保留至少 12 个月。

「为什么重要」：智能体基础设施正走向工程化与可扩展——交友产品若要把「AI 助聊、智能客服、内部运营 agent」接入更多外部工具与数据源，无状态、可水平扩展、鉴权更稳的 MCP 是更适合生产环境的底座。

**推理价格继续跳水：OpenAI 将 GPT-5.6 Luna 输入价降 80% 至每百万 token 0.20 美元**

据模型追踪站汇总，OpenAI 近期将轻量档 GPT-5.6 Luna 的输入价下调约 80% 至每百万 token 0.20 美元，其产品线现覆盖 Luna、Terra、Sol 三档，鼓励团队把常规任务路由到低价模型、把深度推理留给强档。整个 8 月上旬 AI 行业的主线被概括为「更低的成本、更多嵌入日常产品的 agent、更紧的美国与欧盟监管」。

「为什么重要」：单位推理成本持续下降，意味着把 AI 大规模铺进交友产品的每一次匹配、每一条 push 文案、每一次内容审核在经济上越来越可行；分档路由（便宜档跑量、强档兜底）应成为 CMB 侧默认的成本工程范式。

# AI 与科技日报 — 2026-11-26

## 今日头条：Claude 一句话生成的工具能装成桌面应用了，最高权限可读写删文件

Anthropic 11 月 24 日起向全部套餐 Beta 推出「Install as app」：用户用一句话让 Claude 生成的 Artifact 小工具，可直接安装为 Mac 或 Windows 桌面应用，拥有独立图标与窗口，无需打包、签名或配置 API 密钥，改动 Artifact 后应用自动更新。应用分三档权限：默认仅限浏览器能力；应用权限可发通知、用全局快捷键、窗口置顶；最高档「完全访问电脑」可运行程序、读写与删除文件，且 Anthropic 事先不审核。应用须联网并登录 Claude 桌面端才能打开，Docs、Slides 与 Sheets 类型暂不支持。

「为什么重要」：对社交与交友产品团队而言，AI 正从聊天框里的助手变成可分发的小软件入口，内部工具的制作门槛被压到一句话；但最高权限不经审核的设定，也把信任与安全责任推给了安装者与分享者。

**OpenAI：GPT-6 系列能直接设计蛋白质，实验室验证 35 个设计成功结合**

OpenAI 11 月 24 日发表研究与预印本：GPT-6 系列通用模型仅凭推理与代码就能设计新蛋白质的三维结构与氨基酸序列，无需调用专用生物模型生成设计。与生物公司 Onava 合作的实验室验证中，GPT-6.2 设计的 322 个迷你结合蛋白里有 35 个（10.9%）成功结合 5 个靶点，包括与癌症和免疫疾病相关的 PD-L1、VEGF-A 等。模型在多数蛋白质设计任务上已接近甚至超过 RFdiffusion 等专用模型，但完整结构预测仍是明显短板。

「为什么重要」：通用大模型正在侵入专用科学模型的领地，科研工具的产品边界将被重写；但 OpenAI 自己承认，氨基酸序列仍由专用模型生成、候选筛选也靠专用工具，离端到端还有距离，相关产品宣传须留有余地。

**xAI 转向出租算力，Anthropic 成最大客户，每月约 31 亿美元**

据《纽约时报》11 月 24 日报道，xAI 自 5 月起向竞争对手出租数据中心算力，Anthropic 已成为其最大客户，合同约每月 31 亿美元，占 xAI 总收入过半；Google 也以每月约 8 亿美元租用其算力。Anthropic 在招股书中披露，与 SpaceX AI 的协议总额最高 1205 亿美元、延至 2029 年，全部容量预计 12 月交付，之后月费约 31 亿美元；2027 年 1 月与 3 月不可取消期结束后，双方均可提前 90 天取消。

「为什么重要」：算力正在从实验室的护城河变成可租赁的商品，连头部模型公司都成了彼此的房东与房客；对做 AI 产品的团队，这意味着推理成本与供应谈判将更受几份巨额租约的牵制，而非单纯的技术竞赛。

**AWS Bedrock 可信访问 API 正式上线，Anthropic 企业安全护栏进入预览**

AWS 11 月 23 日宣布 Bedrock 可信访问计划 API 正式可用，企业可用同一入口发现、申请并加入模型厂商的安全计划；首批上线的是与 Anthropic 共建的企业前沿防护（EFS）与企业数据控制（EDC），均进入公开预览，覆盖 Claude Fable、Mythos 及经网络验证计划使用的 Opus 5.5 与 Sonnet 5.5。EFS 把留存的提示词与输出存在客户自有 S3 存储桶并用客户 KMS 密钥加密，EDC 则用 AWS 托管存储；两种方案下均无人查看留存数据，也不用于训练，风险由自动化监控生成安全案例交客户团队复核。

「为什么重要」：前沿模型进入受监管行业的最大障碍一直是数据去向，这套「数据留在客户手里、监控只看模式」的架构给出了可落地的折中；对出海与合规要求高的社交产品，这是把旗舰模型接进生产环境的新路径。

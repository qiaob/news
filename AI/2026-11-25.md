# AI 与科技日报 — 2026-11-25

## 今日头条：Anthropic 推出 Claude Ship，AI 智能体接管 PR 评审、修复与放行

Anthropic 11 月 23 日发布 Claude Ship（Beta），把 GitHub 拉取请求的全流程交给三个智能体：已正式上线的 Code Review 负责多角度评审并对抗验证发现的问题；新推出的 PR Steward 会处理失败的 CI、合并冲突与评审意见；Claude Approvals 则按团队写在仓库里的策略文件，决定常规改动能否直接放行。开发者也可在 Claude Code 里用 /ship 命令一键走完建 PR、评审与跟进流程。目前仅面向 Team 与 Enterprise 计划的 GitHub 仓库。

「为什么重要」：对社交与交友产品团队而言，AI 正从“写代码”推进到“决定代码能否上线”，评审与放行策略将成为新的工程治理层，越早把策略文件化，越能吃到智能体提效的红利。

**DeepSeek 再融约 150 亿美元，估值约 860 亿美元**

据彭博报道，DeepSeek 11 月完成了第二轮外部融资，募资约 1,000 亿元人民币（约 150 亿美元），投后估值约 860 亿美元，较 6 月首轮时的约 500 亿美元在五个月内上涨逾七成。创始人梁文锋持股稀释至 67.4%，但按此估值计算其身家升至约 550 亿美元，成为全球最富有的 AI 模型创造者。两轮融资合计约 225 亿美元，资金将主要投向算力。

「为什么重要」：中国 AI 实验室的估值曲线正在快速追赶美国同行，算力竞赛的资本密度再上台阶；对出海与本地化 AI 产品而言，DeepSeek 系模型的性价比路线会继续压低推理成本。

**GPT-6.2 Sol 进入 ChatGPT 聊天标签页，免费用户暂不覆盖**

OpenAI 11 月 23 日起向 Plus、Pro、Business 与 Enterprise 用户推送为日常对话调校的 GPT-6.2 Sol，进入 ChatGPT 的 Chat 标签页，免费与 Go 用户暂不覆盖。按 OpenAI 自测，图片理解得分从 GPT-6 的 47.4% 升至 71.7%，复杂指令遵循与敏感对话的安全合规也有提升；GPT-5.6 Sol 与 Terra 将于 12 月 23 日退役。

「为什么重要」：旗舰模型一周内从 Work、Codex 下沉到全量日常对话，聊天入口的默认能力再次抬升；做对话类产品的团队要跟进新一代模型的图片理解与多轮指令能力，否则体验会被默认拉开差距。

**DeepMind 用 Gemini 智能体团队找到更快量子算法，关键步骤提速 290 倍**

Google DeepMind 与 Google Quantum AI 11 月 23 日发表研究：多组 Gemini 4 智能体在 Lean 4 定理证明器中设计并形式化验证了新的量子线路，其中 arcsin 运算成本降低 290 倍，惯性约束聚变模拟成本降低 11.8 倍、所需逻辑量子比特从 5,650 降至 4,338，Grover 搜索也有 2.57 倍提速。团队已开源 Lean 量子算法库与验证过的解法。

「为什么重要」：AI 智能体加形式化验证的组合，让“发现新算法”从人力试错走向可证明正确的自动化搜索；对做 Agent 与科研工具的产品方，这是多智能体协作落地的标杆案例。

**Google 搜索 Personal Intelligence 接入钱包、Drive 与 Gemini 应用**

Google 11 月 23 日宣布扩展搜索 AI Mode 中的 Personal Intelligence：用户可选择接入 Google Wallet（即日起推送），Drive 与 Gemini 应用将在未来几周内跟进，与已有的 Gmail、日历、照片一起为搜索提供个人上下文，例如按消费习惯推荐信用卡权益、按文档内容制定计划。全部连接均为自愿开启，AI Mode 对钱包数据只有只读权限。

「为什么重要」：搜索正在从“查公开信息”变成“懂你的私人助手”，个人数据成为新的护城河；对社交与内容产品而言，用户对“AI 读我数据换便利”的接受度与边界，将直接决定这类功能的生死线。

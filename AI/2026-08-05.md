# AI 日报 — 2026-08-05

## 今日头条：OpenAI、Anthropic、Google 齐聚白宫 AI 安全会议，前沿实验室协同治理再进一步

美国白宫召集 OpenAI、Anthropic、Google 等主要 AI 实验室召开 AI 安全会议（8 月 3 日），围绕前沿模型的风险评估、对齐与国家安全议题展开磋商。与此同时，业界报道 OpenAI、Anthropic、Google、Microsoft、xAI 五家正在合作制定一套通用的「越狱严重度评分」体系，为未来的能力评估提供共同语言。这标志着「政府 + 头部实验室」的软性协同治理模式在美国进一步成型，行业标准的话语权高度集中于少数几家公司。

「为什么重要」：前沿实验室与监管方共建的评估与安全基线，会自上而下渗透到所有基于其 API 的下游产品——交友应用在做 AI 破冰、审核、反诈时，未来大概率要对齐这套「越狱/滥用」标准与披露口径，合规成本与接口约束需提前纳入产品规划。

**MCP 新规范上线：协议转向无状态、可 Serverless 部署，SDK 月下载量达 5 亿**

2026-07-28 发布的 Model Context Protocol 规范将协议改造为完全无状态（stateless），支持 serverless 部署；扩展框架正式引入用于长任务的 Tasks，以及提供交互式 UI 的「MCP Apps」。据报道 MCP 系列 SDK 的月下载量已达约 5 亿次。作为连接 LLM 与外部工具/数据的事实标准，MCP 的工程化成熟度正快速提升。

「为什么重要」：MCP 已是智能体访问业务系统的通用管道。对 CMB 这类应用，用无状态、可弹性伸缩的 MCP 服务把匹配、消息、支付等能力安全地暴露给 AI 助手，是「对话式发现/AI 助理」形态落地的底层前提；越早对齐规范，越省后续重构成本。

**开放与封闭再度分裂：黄仁勋力推开源权重，Anthropic 与 OpenAI 婉拒 Nvidia 安全联盟**

Nvidia CEO 黄仁勋发表公开信，主张开源权重模型对维系竞争与技术领导力至关重要，获 Microsoft、Meta、Google 等高管背书；但 Anthropic 与 OpenAI 均未加入 Nvidia 牵头的 Open Secure AI Alliance。与此同时黄仁勋暗示，Nvidia 对 OpenAI、Anthropic 的投资可能是其最后一批私募投资，战略重心转向芯片（Vera 处理器已被两家用于数据中心）。开放阵营与闭源阵营的路线之争再度公开化。

「为什么重要」：开源/闭源之争直接决定中小团队能用什么、花多少钱用 AI。若开源权重模型持续逼近前沿，交友应用可在本地/私有部署上做用户画像与内容审核，兼顾成本、时延与隐私合规，减少对少数闭源 API 的绑定风险。

**非美前沿：DeepSeek 发布 V4-Flash-0731，中国厂商延续高性价比路线**

据 AI 模型追踪榜单，DeepSeek 于 7 月 31 日推出 DeepSeek-V4-Flash-0731，延续其「高性价比、快速迭代」的打法，是近期被榜单收录的最新前沿级模型之一。叠加阿里通义、字节等厂商的密集更新，非美（尤其中国）模型阵营在推理成本与部署效率上的竞争力持续增强。

「为什么重要」：低价高效的非美模型为出海到亚洲市场的交友产品提供了更划算的推理选项，也意味着本地竞品能以更低成本嵌入 AI 功能；选型时应把这些模型纳入评测矩阵，而非只盯着美系闭源 API。
